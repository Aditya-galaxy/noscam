# Chrome Web Store Submission Guide for NoScam

This document contains the exact metadata, justifications, and answers required to publish NoScam on the **Google Chrome Web Store**.

---

## 1. Store Listing Metadata

* **Name**: NoScam — Protect Payments from Message Scams
* **Summary** (Max 132 chars):
  > Holds irreversible payments, passcodes, and remote-access installs when instructed by an unsolicited message.
* **Category**: Productivity / Security & Safety
* **Language**: English
* **Privacy Policy URL**: `https://aditya-galaxy.github.io/noscam/privacy.html`
* **Support / Source URL**: `https://github.com/Aditya-galaxy/noscam`
* **Upload Asset**: Upload `dist/noscam-extension.zip` (generated by `python3 package.py`).

---

## 2. Single Purpose Policy Statement

> **Single Purpose Description**:
> *"NoScam has a single, strictly defined purpose: preventing users from falling victim to Authorised-Push-Payment (APP) fraud and social engineering scams. It identifies when a user lands on a checkout, payment, or credential form from an unsolicited message, and pauses the irreversible action until confirmed by a calm guardian device or acknowledged at the keyboard."*

## 3. Permission Justifications (Copy-Paste for Reviewer)

Google automated scans flag extensions requesting `<all_urls>` and `downloads`. Use the exact justifications below in the **Privacy Practices** tab:

### A. Host Permissions (`<all_urls>` / `http://*/*` & `https://*/*`)
> **Reviewer Justification**:
> *"NoScam is an anti-fraud security extension designed to stop victims at the moment of payment on imposter scam pages. Because deceptive phishing sites, fake utility portals, and fraudulent checkout gateways can be hosted on any arbitrary domain on the internet, the extension requires broad host permissions to observe navigation origins and gate payment submit events. All evaluation is performed strictly locally on the user's machine (127.0.0.1); no browsing history, form contents, or personal information is ever collected or transmitted to external servers."*

### B. `downloads` Permission
> **Reviewer Justification**:
> *"The extension uses `downloads.cancel` and `downloads.erase` for a single critical safety function: intercepting and aborting remote-access desktop installers (AnyDesk, TeamViewer, QuickSupport, RustDesk) or deceptive APK files when downloaded immediately following an unsolicited incoming message. This prevents scammers on digital-arrest or tech-support calls from gaining live remote control of the victim's machine."*

### C. `webNavigation` Permission
> **Reviewer Justification**:
> *"The extension uses the `webNavigation.onCommitted` and `webNavigation.onCreatedNavigationTarget` events to record navigation transition types (e.g., distinguishing between a user typing an address, opening a trusted bookmark, or clicking an external link from a messaging tab). This provenance is stored in ephemeral session storage and decays after 15 minutes, allowing NoScam to accurately detect when an action is being driven by a message."*

### D. `storage` Permission
> **Reviewer Justification**:
> *"Used to access `chrome.storage.session` to retain tab navigation provenance in memory across the Manifest V3 background service worker's idle termination lifecycle."*

## 4. Privacy Practices Tab Checklist

* **Data Usage Declaration**:
  * Check **"Authentication information"** or **"Personal communications"**? **NO**.
  * Check **"Web history"**? **NO** (NoScam only reads provenance locally in memory during active navigation).
  * Check **"Financial and payment information"**? **NO** (NoScam gates clicks locally; card numbers/bank accounts are never recorded, transmitted, or extracted).
* **Certifications**:
  * [x] *"I certify that this extension complies with the Limited Use policy."*
  * [x] *"I confirm that data is not sold to third parties, used for unrelated purposes, or used for creditworthiness."*

## 5. Submission Walkthrough

1. Open the [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole).
2. Pay the one-time $5 developer registration fee (if new developer).
3. Click **Add new item** → upload `dist/noscam-extension.zip`.
4. Fill in Store Listing, upload screenshots from `docs/held.png` and `docs/scorecard.png`.
5. Enter the permission justifications from Section 3 into the Privacy tab.
6. Click **Submit for Review**. Standard review takes 24 to 72 hours.
